# 网球代码优化与验证完整性 — 2026-10-26

本轮已在本地完成代码、训练产物和验证。未推送 GitHub、启用线上网球任务或部署 VPS。免费数据范围保持不变，无需 API Key。

## 已完成

1. 正式训练生成三盘／五盘、赛事层级及两者交叉分组的回测。A、B 双方正负让盘／让局，以及胜者与局差联合事件分别有标签和成绩。API 不再借用不匹配的混合统计。
2. 精确比分补充真正的整场单选命中率，不用大量“该比分未出现”的二元判断冒充比分预测准确率。
3. 每个盘口提供冻结频率基线、命中率差、Log loss／Brier 改善、模型是否始终选择同一结果、测试是否只有一类结果，以及基线样本量。`retrospective_accuracy_above_baseline` 只表示回顾命中率高于基线，不表示统计显著或未来有效。
4. 盘内局数增加按盘号及盘制区分的比分候选，并向总体和实力／场地条件分布收缩。完整路径仍由终局盘分重新加权，保持胜负、总盘数、总局数、每盘与让分概率一致。
5. 候选只用较早年份选择：2012—2022 拟合、2023 选择／重新拟合、2024 温度校准。2025+ 是复用过的回顾测试。WTA 验证不支持新候选，保留原模型。
6. 刷新先在暂存目录完成数据、胜负、旧比分对照和新比分模型，检查哈希及分盘制报告后发布。加载与发布使用文件锁，捕获到发布失败时回滚旧文件。异常断电没有持久化事务日志，仍依靠哈希检查拒绝不匹配的比分配置。
7. 严格检查盘制、盘号、有限概率、二元标签、正则化参数、签表必需选手和阶段、HTTP JSON 对象及比赛层级。签表输出明确标记尚无历史回测；未使用的旧比分配置不再阻断有效新模型。

| WTA 主巡回 | 1.847412 | 1.847637 | 保留共享模型 |
