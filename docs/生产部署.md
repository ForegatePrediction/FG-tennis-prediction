# 网球生产部署与维护

代码与模型独立版本化。`/opt/fg-tennis-current` 指向经过验证的代码发布目录；模型位于 `/var/lib/foregate/tennis/models/<sha256>`，`current` 为原子切换的软链接。统一网关仍使用原域名和 `/predict?type=tennis`。生产不启用 `--demo`。`/predict` 支持不依赖赛事索引的球员基础预测，也支持已审核的赛事路径；`mode=fixture` 可保留严格赛事检查，详见 [GET 接入](Foregate-GET接入与联调.md)。

## 调度

- GitHub `daily.yml`：北京时间 13:30，免费历史采集、完赛合约增量校验、训练、完整测试，通过后发布独立 GitHub Release。保留原 Actions 模型制品。
- VPS `fg-tennis-model-update.timer`：北京时间 14:30，最多约 1 分钟随机延迟。公开下载模型包，不保存 GitHub Token；检查 SHA256、压缩包成员、模型和校准配置的一致性、快照和来源新鲜度后切换。更新后重启网关并检查健康；失败恢复上一模型代。
- VPS `fg-tennis-fixtures.timer`：每 15 分钟，最多约 30 秒随机延迟。抓取免费 Gamma 赛程，并严格匹配有官方依据、日期范围明确的赛事登记。网络／分页错误保留原索引；请求端拒绝超过 48 小时未核查的记录。

完赛基线保留经核实的历史种子，重查近期已结算合约，保留 17 天成熟期及原回顾性验证流程。采用至少 45 天重叠窗口；窗口之外新修订或长期未结算后才出结果的合约可能漏记，该限制在发布模型中记录。不会把重建时间冒充源数据更新时间。历史标签冲突会阻止发布，失败时继续使用上一模型并暴露真实年龄。

## 生产配置

网关 systemd drop-in 使用：

```ini
[Service]
Environment=FG_TENNIS_DIR=/opt/fg-tennis-current
Environment=FG_TENNIS_MODEL=/var/lib/foregate/tennis/models/current/current.json
Environment=FG_TENNIS_FIXTURES=/var/lib/foregate/tennis/fixtures.json
```

`deploy/` 中提供 fixture 和模型更新的 systemd 单元；`model-update.sh` 安装为 root 所有的 `/usr/local/libexec/fg-tennis-model-update.sh`，实际下载和数据写入使用 `fggateway` 身份，和现有代码发布共用部署锁。脚本更新后需显式重新安装，不会由不受信任的网络数据覆盖。

约 1 GiB VPS 首次仅加载 ATP/WTA 主模型。独立扩展模型本地累计加载峰值约 782 MiB，不在该容量下同时启用。主模型不覆盖 Challenger、资格赛、ITF、双打或青少年。未来启用扩展模型须先评估资源和独立验证范围。

2026-10-26 首次生产核查导入 42 场（ATP 32、WTA 10），其中 41 场可预测、655 个盘口、1,310 个 Poly Token 选项绑定。Mika Brunold 缺少主模型历史，所在一场明确不可用。这是当时赛程的动态快照。赛事登记仅核实 Swiss Indoors Basel、Erste Bank Open 和 Pan Pacific Open（含 Toray 名称别名），有效日期为 2026-10-26 至 2026-11-01。后续周次、其他赛事及赛制须继续核实并更新 `config/competitions-reviewed.json`；定时抓取不会自动把未知场地或赛制当作已审核。

## 检查与回滚

检查 `/health` 中 `engines.tennis` 的模型年龄、来源年龄及 `foregate` 索引状态；`foregate.player_prediction_available` 表示球员基础预测入口可用，`foregate.status` 仍单独描述赛事索引；索引为空不禁止比较两名已知球员。同时检查两个 timer 最近一次 service 的退出状态。`foregate.automatic_collection=true` 表示使用自动生成的索引，不代表所有比赛已覆盖。

模型回滚：将 `models/current` 原子切回上一个已验证 SHA256 目录并重启 `fg-gateway`。代码回滚：切回上一代码软链接，必要时移除本次网球 drop-in，重启网关并核验原四引擎。失败代保留以便排查，不删除当前模型代。

所有输出保持 `contract_ready=false`。比分玩法仍以正常完赛为条件，是否完赛是历史总体基线；Other 和全部退赛／取消结算尚未验证。赛前真实 API 已可运行不等于交易合约适配全部完成。
