# 网球生产上线验收

日期：2026-10-26。网球后端已部署至现有 VPS，经原域名统一网关提供服务。本文记录后端验收；不表示已经修改 Foregate 的生产前端。

## 地址与调用

- 健康检查：[生产网关 /health](https://gateway.watchlived.cc/health)。五引擎 football、basketball、esports、price、tennis 均返回 `ok`。
- ATP 实测：`GET /predict?type=tennis&tour=atp&a=Hubert%20Hurkacz&b=Zizou%20Bergs&eventSlug=atp-hurkacz-bergs-2026-10-27&lang=zh`。
- WTA 实测：`GET /predict?type=tennis&tour=wta&a=Alycia%20Parks&b=Maja%20Chwalinska&eventSlug=wta-parks-chwalin-2026-10-27&lang=zh`。

示例对应当时已核实的未来赛程；开赛后会返回不可预测，不能把固定 URL 当作永久可用演示。使用真实 `matchStartTime`，不从 slug 日期猜开赛时间。

实际盘口返回 `polyMarketId` 和字符串 `poly_outcomes[].assetId`、`probability`。Foregate 用其与 detail 的 `yesAssetId/noAssetId` 对齐；Gamma 市场 ID 不能冒充 Foregate 的 outcomeId。未知赛事、球员与赛事不符均实测返回 `ready=false`，不会补造概率。

## 逐场覆盖

首次采集扫描 636 个开放网球事件，按赛事日期、主巡回赛单打及核实赛制导入 42 场。索引覆盖不等于预测覆盖。

| 范围 | 已导入 | 可预测 |
| --- | ---: | ---: |
| ATP | 32 | 31 |
| WTA | 10 | 10 |
| 合计 | 42 | 41 |

41 场共 655 个真实盘口、1,310 个选项，逐项验证概率合法、二元概率归一、Token 保持字符串并绑定。不可预测的一场为 Mika Brunold 对 Nuno Borges：Mika Brunold 缺少主模型历史，不使用模糊同姓匹配或市场价格替代。

实际事件出现 10 类盘口：胜负、完赛、第一盘胜者、后续盘胜者、大小盘、第一盘大小局、后续盘大小局、全场大小局、让盘、让局。当前这些事件没有精确比分盘口，不能声称实测了真实精确比分合约。另用真实赛程背景加显式参考盘口，在生产 API 验证全部 11 类、35 项计算；该参考查询不带真实市场绑定。

当前审核三项赛事 Basel、Vienna、Tokyo，日期范围 10 月 26 日至 11 月 1 日，详见[维护说明](生产部署.md)。不能外推为四大满贯或全部 Poly 已覆盖。约 1 GiB VPS 只加载主模型；Challenger、资格赛、ITF、双打、青少年不在本次生产范围。

## 调度与边界

北京时间 GitHub 每天 13:30 采集、训练及测试；VPS 每天 14:30 校验并应用最新公开 Release；VPS 每 15 分钟重采真实赛事。模型同步不在服务器保存 GitHub Token。更新有 SHA256、压缩包内容、模型配置一致性及健康检查，失败保留或恢复前代。代码发布目录和模型目录分别版本化。

全部研究概率保持 `contract_ready=false`。比分玩法以正常完赛为条件，完赛与否使用历史总体概率；Other、退赛、取消及全部合约结算语义尚未完成验证。赛果按保守赛事结束窗口纳入，免费数据源、模型年龄及球员历史时效通过 API 明示，不承诺实时结果或完整 Poly 覆盖。
